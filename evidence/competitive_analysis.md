## Detailed Breakdown

### LeetCode
- **Pros:** Best for raw DSA practice, huge community, great discussion forums.
- **Cons:** Only focuses on DSA. Premium is required for company tags. Poor for CS Fundamentals and System Design.

### InterviewBit
- **Pros:** Gamified experience, good company-specific paths.
- **Cons:** Outdated UI, limited question bank, misses out completely on non-DSA aspects like HR.

### GeeksforGeeks (GFG)
- **Pros:** Enormous repository of articles covering everything from DSA to CS Core.
- **Cons:** Cluttered, overwhelming, difficult to track actual progress, hard to filter out noise.

### Striver's SDE Sheet / TakeUForward
- **Pros:** Excellent curation of top questions, high trust among students.
- **Cons:** Usually tracked via manual spreadsheets (Google Sheets). Requires manual effort with zero intelligence or analytics.

### Pramp
- **Pros:** Good for peer-to-peer mock interviews.
- **Cons:** Scheduling is a hassle, relies on peer quality which is inconsistent.

### PrepInsta
- **Pros:** Great for service-based companies.
- **Cons:** Not deep enough for product-based companies, feels more like a course platform than a prep tool.

## The Gap PrepSync Fills
Existing tools are severely fragmented. A typical student uses LeetCode for DSA, GFG for concepts, YouTube for explanations, and Google Sheets for tracking. PrepSync unifies this workflow, offering a single intelligent dashboard to track progress across DSA, CS Core, System Design, and HR, while providing smart analytics to overcome preparation paralysis.
